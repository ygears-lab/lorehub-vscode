## [Unreleased]

### Added

- Cloud-synced Markdown library tied to a GitHub account.
- Create, import, edit and delete Markdown files from a WebView panel.
- Labels with live counts, multi-select filtering, rename and delete.
- Search by title and filename, with the list sorted by most recently updated.
- Load a file into the workspace, with a diff shown before overwriting an existing file.
- Offline reading from a local cache; editing is disabled until the connection returns.
- Keyboard shortcuts for new, save, search and list navigation.
