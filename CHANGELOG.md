# Changelog

## 0.1.0 (10 September 2026) PreRelease

Initial release!

- Cloud-synced Markdown library tied to a GitHub account.
- Create, import, edit and delete Markdown files from a WebView panel.
- Labels with live counts, multi-select filtering, rename and delete.
- Search by title and filename, with the list sorted by most recently updated.
- Load a file into the workspace, with a diff shown before overwriting an existing file.
- Offline reading from a local cache; editing is disabled until the connection returns.
- Keyboard shortcuts for save, search, list navigation and dismissing popovers.
- A LoreHub button in the editor title bar for `CLAUDE.md`, `AGENTS.md`, `SKILL.md` and `.cursorrules`.
- Load into a folder directly from the Explorer context menu.
- A "Get started with LoreHub" walkthrough.
- An optional status bar item showing the sign-in state (`lorehub.statusBar.enabled`, off by default).
- Japanese UI, following the VS Code display language.
