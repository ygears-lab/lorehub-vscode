# LoreHub

**自分のmdライブラリを、アカウントに紐づけてクラウドに置く。VS Codeの中で。**

*[English](README.md)*

`CLAUDE.md` や `SKILL.md`、`.cursorrules`、`AGENTS.md` を集めてはいるけれど、
リポジトリやGist、そのとき使っていたマシンのフォルダに散らばっていて、
新しいプロジェクトを始めるときに「あれ、どこだっけ」となる。

LoreHubはそれを1箇所にまとめます。置き場所はマシンではなくあなたのアカウントで、
いま開いているプロジェクトからワンクリックで取り出せます。

## LoreHubを作った理由

この領域のツールはほとんどがローカルファースト、つまりライブラリは1台のPCの1つのフォルダに置かれます。
LoreHubは逆の作りにしています。

- **マシンではなくアカウントに付いてくる。** 新しいPCでGitHubログインすれば、ライブラリはもうそこにあります
- **エディタから出ない。** Webアプリに切り替える必要も、フォルダを覚えておく必要もありません
- **たくさん集める人のための整理。** ラベル・件数表示・検索は、5個ではなく増え続けるライブラリを前提に設計しています

## 機能

**書く／取り込む**
パネル内でmdを新規作成できます。ディスク上にある既存のファイルをインポートすることもできます。

**ラベルで整理する**
1つのmdに好きなだけラベルを付けられます。サイドバーは全ラベルを件数付きで表示するので、
どのラベルが育っていて、どれが空なのかが一目で分かります。1つでも複数でも絞り込めます。

<!-- SCREENSHOT 2 — 3ペイン（ラベル／md一覧／エディタ）の全体像。 -->

**あとから見つけられる**
ラベル絞り込みに加えて、タイトルとファイル名で検索できます。
一覧は更新日時の新しい順なので、実際に使っているものが自然と上に来ます。

**プロジェクトにロードする**
ワークスペースにmdを書き出せます。配置先は毎回選びます。
同名のファイルが既にある場合は、上書きする前に差分を表示するので、
何が変わるのかを確認してから決められます。

<!-- SCREENSHOT 3 — 上書き前に表示される差分。 -->

**オフラインでも読める**
ネットワークが切れていても、取得済みのライブラリは閲覧できます。
編集はオンラインに戻るまで無効になるので、変更が黙って失われることはありません。

## 使いはじめる

1. 拡張機能をインストールする
2. コマンドパレットから **LoreHub: Open My md Files** を実行する
3. GitHubでログインする
4. mdを作る（またはインポートする）→ ラベルを付ける → プロジェクトにロードする

### キーボード操作

| ショートカット | 動作 |
| --- | --- |
| <kbd>Ctrl/Cmd</kbd> + <kbd>N</kbd> | 新規作成 |
| <kbd>Ctrl/Cmd</kbd> + <kbd>S</kbd> | 保存 |
| <kbd>/</kbd> | 検索へフォーカス |
| <kbd>↑</kbd> <kbd>↓</kbd> | 一覧を移動 |
| <kbd>Esc</kbd> | 検索クリア／ポップオーバーを閉じる |

以下はコマンドパレットからも実行できます。
**Open My md Files** / **Load md into Project** / **Login with GitHub** / **Logout**

## データの取り扱い

保存したMarkdownはLoreHubのSupabaseに保存され、あなたのGitHubアカウントに紐づきます。
全ての行はPostgreSQLの行レベルセキュリティ（RLS）で保護されており、他のユーザーから読むことはできません。
認証トークンはVS CodeのSecretStorageに保存され、平文で置かれることはありません。

プロジェクトにロードしたファイルは、あなたのマシンにだけ書き出されます。
LoreHubがワークスペースの他の部分を読むことはありません。
